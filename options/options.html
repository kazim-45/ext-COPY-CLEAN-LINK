Everything runs on your device. No network requests, no analytics, nothing synced.

Automatic protection

These two features need permission to run on websites. They're off until you turn them on, and you can take the permission back any time.

Behavior

Keyboard shortcut (default Alt+Shift+C) and right-click menu entries Copy clean link address / Copy clean page URL work with no extra permissions. Change shortcut

Your own parameters

One per line (or comma separated). A trailing * matches a prefix, e.g. campaign_*. Case-insensitive when copying. Automatic stripping uses exact, lowercase names only.

Paused sites

Automatic stripping is skipped on these sites. Add one here or use the toggle in the toolbar popup.
